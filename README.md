# 禾伴在线版

面向长辈的生活操作指引与家庭互助工具。用 ChatGPT 登录后，提醒、设备卡和指引进度按账户保存。家人用一次性邀请码连接后，可以分享单个问题或已保存的设备卡，并随时撤回。

在首页或「问问助手」打开「拍照取证」，可使用相机或选择相册里的照片。预览后选择场景、填写备注，再保存到「我的记录」。照片会压缩为 JPEG，保存时间由服务器记录。照片及备注仅账户本人可查看和删除。根据所选场景，记录页提供对应的使用指引。

在当前目录用 Node.js 24 或更新版本运行 `npm start`，打开 `http://127.0.0.1:4180`。本机提供两个测试身份，数据放在 `.local/`。线上身份由 ChatGPT Sites 处理，本机测试入口不会被打包。

- `npm run check` 检查脚本语法。
- `npm test` 验证身份、数据隔离、跨账户分享和撤回，以及现场照片的存取与删除。
- `npm run build` 生成 Sites Worker。

`api.js` 使用 Sites 注入的登录身份。D1 保存账户数据、邀请和分享，以及现场记录的备注与时间。R2 保存照片。更新时检查版本号，避免不同设备误覆盖。应用里的邀请码只建立家人连接，站点是否允许他人访问仍由 ChatGPT Sites 权限控制。

取件和查账单使用示例画面。实际运营前应逐点核验。聊天使用内置场景答复，提醒在打开应用时生效，也可导出为日历文件。
