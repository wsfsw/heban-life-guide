# 禾伴在线版

面向长辈的生活操作指引与家庭互助工具。游客直接进入，提醒、设备卡、指引进度和现场照片保存在当前浏览器。用称呼和邮箱创建禾伴账户，使用设备通行密钥确认后可把新记录存到云端。邮箱是账户标识，使用的是设备认证。游客记录与云端记录各自保留。家人用一次性邀请码连接后，可以分享单个问题或已保存的设备卡，并随时撤回。

在首页或「问问助手」打开「拍照问一问」，可使用相机或选择相册里的照片。预览后选择场景、填写备注，再保存到「我的记录」。照片会压缩为 JPEG。云端照片及备注仅账户本人可查看和删除。根据所选场景，记录页提供对应的操作步骤。

在当前目录用 Node.js 24 或更新版本运行 `npm ci` 和 `npm start`，打开 `http://127.0.0.1:4180`。测试设备登录时可设置 `HEBAN_HOST=localhost` 后使用 `http://localhost:4180`。本机数据放在 `.local/`。两个本机测试身份可经「找回旧版记录」进入，测试入口只在本地预览提供。

- `npm run check` 检查脚本语法。
- `npm test` 验证身份、数据隔离、跨账户分享和撤回，以及现场照片的存取与删除。
- `npm run build` 生成 Sites Worker。
- `npm run build:pages` 生成可发布到 GitHub Pages 的 `dist-pages/`。将该目录的内容作为 Pages 发布源。体验版打开即进入游客模式，提醒和照片保存在当前浏览器。登录与家庭连接可从页面打开云端版。

`api.js` 验证 WebAuthn 凭据，并使用仅 HTTP 可读的会话 Cookie。D1 保存账户、会话、邀请和分享，以及现场记录的备注与时间。R2 保存照片。更新时检查版本号，避免不同设备误覆盖。旧版记录仍可通过原来的 ChatGPT Sites 身份访问。

在「拍照问一问」预览照片，填写想完成的事，点「请助手看看」获得操作步骤、核对点和下一步选择。在线聊天和照片分析使用 DeepSeek。问答发送最近的对话，方便继续追问。连接失败时可重试，也可打开「跟着做」查看操作步骤。`DEEPSEEK_API_KEY` 由助手后台的运行时密钥管理。照片只在点击分析时发送，记录仍由用户单独保存。

`npm run build:assistant` 生成独立的 `dist/assistant/index.js`，可作为 Cloudflare Worker 部署。将 `scripts/assistant-schema.sql` 应用于单独的 D1 数据库，将该库绑定为 `DB`，并配置 `DEEPSEEK_API_KEY`。发布 GitHub Pages 时，可将 `HEBAN_ASSISTANT_ORIGIN` 设置成独立后台的 HTTPS 域名，再运行 `npm run build:pages`。已配置的独立后台会接手问答和照片分析。登录及家庭连接仍通过原云端入口提供。

从「家属端 → 长辈端常用功能」添加内置入口或 HTTPS 网页。已连接的家庭账号可以把入口同步到长辈的首页。游客入口保存在同一个浏览器。

取件和查账单使用示例画面。提醒在打开应用时生效，也可导出为日历文件。
